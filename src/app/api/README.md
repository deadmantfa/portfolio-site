# src/app/api

## Overview
The `src/app/api` directory serves as the root container for server-side HTTP API routes in the application. It organizes endpoint implementations for external integrations and client interactions.

## Subdirectories & Boundaries
- chat: [./chat/README.md](./chat/README.md) - Conversational AI route handler providing failover inference across Anthropic and Google Gemini APIs.
